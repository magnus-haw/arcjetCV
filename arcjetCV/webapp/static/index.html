Welcome to arcjetCV

Segment the sample and shock in arc jet test videos, track leading-edge recession frame by frame, and turn the results into publication-ready time series. Everything runs on your own computer.

      Using arcjetCV Web

      A browser front end for the same arcjetCV processing engine used by the desktop GUI.

      Launching

      After installing arcjetCV, start the web interface from a terminal:

      pip install "arcjetcv[web]"
arcjetcv-web

      Your browser opens at http://localhost:5050. Leave the terminal open while you work and press Ctrl+C to stop. Useful options:

      • --port 8080 use another port
      • --no-browser do not open a browser tab
      • --host 0.0.0.0 allow other machines on your network (trusted networks only)

      Using the page from a website

      The same page can be hosted on a website while all processing stays on your computer. Start the engine for that page once:

      arcjetcv-web --site https://your-site/arcjetcv/

      The browser opens the website already connected to arcjetCV on this computer. The site is remembered, and only that website, with your private access token, can use the engine. Site owners create the files to upload with arcjetcv-web --export-site FOLDER.

      Where files go

      Videos are read in place. The .meta file and the output NAME_FIRST_LAST.json are written next to the video, exactly like the desktop GUI, so both tools can share results. Files dropped into the browser are copied to ~/arcjetCV_workspace.

      Segmentation methods

      • CNN: U-Net model, most robust. Needs PyTorch and the model checkpoint.
      • AutoHSV: automatic colour thresholds. Good default without a GPU.
      • HSV: manual hue, saturation and intensity ranges for model and shock.
      • GRAY: grayscale threshold, uses the model minimum intensity.

      Tips

      • Drag on the frame with Draw crop on to set the region of interest; the crop is saved to the .meta file.
      • Use ← / → to step frames and Shift for steps of 10.
      • Positions are signed so downstream motion is positive for both flow directions.
      • Recession rate is a linear fit of the model center after the recession start (the frame of maximum swelling).

        Connect to arcjetCV on this computer

        This page is only the interface. Your videos are read and processed by the arcjetCV engine running on your own computer, so nothing is uploaded.

        pip install "arcjetcv[web]"

        2. Start the engine for this page:

        arcjetcv-web --site URL

        Your browser then reopens this page already connected. If it asks to let this site access apps on your device, click Allow.
